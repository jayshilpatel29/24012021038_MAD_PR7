# MAD Practical 7 – Mobile Application Development

## 📱 Project Overview

This project is developed as part of the **Mobile Application Development (MAD) Practical 7** coursework. It demonstrates the development of an Android application using Android development tools and programming concepts.

The project focuses on understanding Android application structure, user interface development, application execution, and fundamental mobile app development practices.

## 🎯 Objectives

- To understand the Android application development process.
- To learn how to create and manage an Android Studio project.
- To implement user interface components.
- To understand activity lifecycle and event handling where applicable.
- To develop, build, and test an Android application.
- To gain practical experience with mobile application development.

## 🛠️ Technologies Used

- **Development Environment:** Android Studio
- **Platform:** Android
- **Programming Language:** Kotlin or Java, depending on the project implementation
- **Build System:** Gradle
- **Version Control:** Git and GitHub

## ⚙️ Requirements

Before running the project, ensure that you have:

- Android Studio installed.
- Android SDK configured.
- A compatible Android device or Android Virtual Device (AVD).
- JDK compatible with the project's Gradle configuration.
- Git installed (optional, for cloning the repository).

## 🚀 Installation and Setup

### 1. Clone the Repository

Open a terminal and execute:

```bash
git clone https://github.com/jayshilpatel29/24012021038_MAD_PR7.git
```

### 2. Open the Project

1. Launch Android Studio.
2. Select **Open**.
3. Navigate to the cloned project folder.
4. Wait for Gradle synchronization to finish.

### 3. Configure the Emulator

1. Open Device Manager in Android Studio.
2. Create or select an Android Virtual Device.
3. Start the emulator.

Alternatively, connect a physical Android device with USB debugging enabled.

### 4. Run the Application

1. Select the application configuration in Android Studio.
2. Choose the emulator or connected device.
3. Click the **Run ▶** button.
4. Wait for the application to build and launch.

## 🧪 Testing

The application can be tested using the Android Emulator or a physical Android device.

Recommended checks include:

- Verify that the application launches successfully.
- Check the displayed user interface.
- Test available buttons and user interactions.
- Check application behavior during navigation.
- Review the Logcat output for runtime errors.
